## 1. Resumen y alcance
Este proyecto tiene como objetivo **La implementación didáctica de una solución acotada, funcional, reproducible y documentada compuesta de una web API, una interfaz web sencilla y una base de datos.**, incluyendo:

- Funcionalidades principales.
Captura, modificación, eliminación y actualización de solicitudes de compra.  
Generación de un reporte de las ventas realizadas entre distintas fechas y un resumen global de ventas por estado y su importe total.

## 7. Decisiones y alternativas
Base de datos: SQL LocalDB por practicidad ya que no se requiere configuración compleja y esta integrado con Visual Studio  
Framework backend: .NET 10 por rendimiento y soporte a largo plazo al ser una versión tipo LTS.  
Alternativas evaluadas: SQL SERVER DEVELOPER, MySQL, SQL EN DOCKER.
